## Overview

LangChain is a framework for developing applications powered by language models. This repository contains a set of examples that demonstrate how to use LangChain to build everything from simple LLM calls to complex agents and retrieval-augmented generation (RAG) systems, including advanced retrieval techniques such as HyDE, multi-query retrieval, reranking, adaptive RAG, and RAG-Fusion. RAG-Fusion is available as a standalone example
